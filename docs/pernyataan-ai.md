# Pernyataan penggunaan AI

Dicatat sesuai ketentuan lembar pernyataan kontribusi. Setiap bantuan AI ditulis ringkas di sini.

Alat: Claude Code (Anthropic).

| Tanggal | Bagian | Yang dibantu AI | Yang diputuskan atau diperiksa tim |
| --- | --- | --- | --- |
| 2026-11-25 | Perencanaan | Usulan stack, tahapan pengerjaan, usulan nama aplikasi | Tim memilih nama Tirai, React, Express, SQLite, JavaScript biasa |
| 2026-11-25 | Langkah 0 | Kerangka proyek: konfigurasi Vite dan Express, halaman awal, tes kesehatan server, README, dokumen arsitektur awal | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 1 | Skema SQLite, inventaris alasan tiap kolom, data sintetis (nama, alamat, kondisi dikarang), hash kata sandi scrypt, tes skema dan minimisasi, dokumen database | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 2 | Sesi cookie, batas percobaan masuk, kebijakan RBAC, endpoint API, header keamanan, halaman masuk dan dasbor sederhana, tes matriks peran x endpoint, dokumentasi API | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 3 | Enkripsi kolom AES-256-GCM, kunci data per pemilik terbungkus kunci master, HMAC NIK, pendaftaran mustahik oleh amil, tes ciphertext di disk, dokumentasi batasan | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 4 | Tabel audit log append-only dengan trigger, pencatatan per aksi dan per orang, endpoint baca untuk admin, tampilan audit log, tes | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 5 | Beranda: buku kas peragaan dengan animasi tirai, angka berputar, log meluncur, bagian Cara Tirai menjaga data, gaya tampilan, pemeriksaan reduced-motion dan aksesibilitas dengan Playwright | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 6 | Dasbor Data saya (data, riwayat akses, ekspor JSON/CSV, permintaan hapus), hak mustahik lewat amil, pemrosesan permintaan oleh admin dengan anonimisasi, dasbor bendahara/amil/admin, tes | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 7 | Tabel persetujuan per tujuan dengan akibat nyata (hapus kontak, sembunyikan nama dari bendahara), endpoint dan sakelar izin di Data saya, tes | (diisi tim setelah memeriksa) |
| 2026-11-25 | Langkah 8 | Catatan pribadi E2EE terbatas (Web Crypto: PBKDF2 + AES-GCM di browser), endpoint penyimpan ciphertext, tes, pemeriksaan XSS di browser, indeks bukti uji, skrip pemeriksaan Playwright | (diisi tim setelah memeriksa) |

Catatan: AI tidak dipakai sebagai sumber teks ayat, hadis, atau pasal undang-undang. Semua rujukan semacam itu diperiksa manusia ke sumber asli.
